# Eimak's Boogers — The Temple of Rivieris

A free static website for the fantasy league's weekly Oracle predictions.

## Free hosting

The easiest free option is GitHub Pages or Cloudflare Pages. Upload the contents of this folder as a static site.

## Weekly workflow

1. The commissioner provides the actual matchups and starting lineups for the week.
2. Current NFL/fantasy expert analysis is used to evaluate the players and matchup.
3. The commissioner publishes the resulting prophecy to the site.
4. League members use the same link to read the current week and the growing Eimak history.

## Important

The current site is a public/static prototype. Its local editing controls are not a secure online admin system. For the first version, the safest workflow is to update the published data before deploying each week's version. A later version can add a proper private commissioner dashboard and persistent online database.

## Domain

`eimaksboogers.com` is an excellent final domain name. The hosting can remain free, but the custom `.com` domain itself normally needs to be purchased separately.
